# TOP1 metric review — 17 October 2026

## Decision rule

Keep a distinct, interpretable observation or reproducible performance test that fits a simple training platform. Remove redundant entries, ambiguous device scores, specialist clinical investigations and exposure totals from the active game. These are product decisions, not claims that the removed measurements are medically useless.

**16 active optional measurements: 2 body markers, 12 performance tests, 2 recovery observations.** TOP1 tiers remain illustrative product benchmarks. A useful measurement does not automatically have a defensible world percentile. Missing data is never zero-filled.

## Kept: individual decisions

| Metric | Why it earns a place | Important limit |
|---|---|---|
| Body fat | Describes body composition beyond tape measurements | Method-dependent estimates; compare the same method, no reward for extreme leanness |
| Waist-to-height ratio | Simple, inexpensive central-adiposity observation | Different construct from body-fat percentage; consistent anatomical site; not a diagnosis |
| Strict push-ups | Accessible upper-body endurance test | Same depth, trunk position and full extension; other variants are different tests |
| 30-second sit-to-stand | Accessible lower-body functional endurance | Same chair and technique; ceiling effects in fit younger adults; not maximal leg strength |
| Eyes-closed single-leg balance | Distinct balance and proprioceptive task | Same leg, surface and stopping rules; test beside stable support |
| Bench press / body weight | Upper-body pressing strength | Consistent lift standard; ratio depends on body weight; safe submaximal estimate available |
| Single maximum handgrip | Low-complexity force test with a loaded published reference | Hydraulic seated protocol needed for published comparison; not a sum of both hands |
| VO₂ max | Aerobic capacity, distinct from strength | Direct CPET and field/wearable estimates are not interchangeable; published reference gated by protocol |
| Squat / body weight | Lower-body squat strength | Consistent depth, equipment and technique; no need for unsafe maximum attempts |
| Deadlift / body weight | Hip-hinge pulling strength | Different movement from squat; consistent equipment and technique |
| Weighted pull-up / body weight added | Vertical pulling strength | Added load and total system load are different quantities; same strict technique |
| Countermovement jump | Vertical explosive power with a loaded published reference | Published comparison needs exact Leonardo protocol; estimates remain illustrative otherwise |
| Standing broad jump | Accessible horizontal explosive power | Different direction/task from vertical jump; same start, surface and landing measurement |
| 10-metre sprint | Distinct acceleration performance | Advanced optional test: electronic gates and consistent start/setup; hand timing not comparable |
| Total sleep time | Understandable recovery habit, diary or consistent device | Seven-day average; longer is not endlessly better; duration is not sleep quality |
| Resting heart rate | Real, inexpensive rested physiological trend | Moved to Recovery; influenced by medication, stress, illness and other factors; lower is not always better |

## Removed from active game: individual decisions

| Metric | Reason for removal |
|---|---|
| ApoB | Useful cardiovascular risk test; clinical interpretation rather than a training-performance competition |
| Lipoprotein(a) | Useful inherited-risk marker, largely genetic; unsuitable as a lifestyle progression target |
| Fasting insulin | Clinical context and assay variability; not a standardized performance test |
| hs-CRP | Nonspecific inflammatory marker, including transient illness/exercise effects; not a recovery rank |
| HbA1c | Useful longer-term glycemic marker; clinical interpretation and individual targets, not a fitness tier |
| Homocysteine | Specialist clinical context; no defensible universal performance target in TOP1 |
| Cystatin C | Kidney-function assessment; clinical context, not athletic achievement |
| GGT | Liver enzyme with multiple influences; not direct exercise performance |
| Fasting glucose | Useful clinical measurement; does not justify a universal training rank or lowering it indefinitely |
| Visceral fat area | Meaningful imaging measure, but current device/DEXA/area conventions are not interchangeable; specialist burden and overlap with simpler composition observations |
| Combined handgrip | Real force measure with a distinct Canadian reference; removed to avoid a second grip entry inflating one capacity. Never convert old sums into single-hand values |
| Zone 2 power | Useful within a defined endurance protocol, but “Zone 2” thresholds and devices differ; current input lacks a reproducible shared threshold definition |
| Peak expiratory flow | Useful respiratory assessment; reference equations and clinical context required; not general cardiovascular fitness |
| Farmer’s carry | Real task, but current duration-only format omits consistent distance, speed, turning and implements; overlaps grip and loaded strength |
| 1-minute heart-rate recovery | Real physiological measure, but workload, recovery posture and active/passive protocols materially affect results; too much setup for this simplified inventory |
| HRV | Useful individual trend under consistent conditions; not a universal “higher is better” rank across people/devices |
| Circadian regularity /100 | Regularity matters, but the existing number does not specify a reproducible computation. It is not automatically the research Sleep Regularity Index |
| Sleep efficiency | Real asleep/time-in-bed ratio, but current device estimates and missing denominator/method make comparisons weak. Avoid encouraging reduced time in bed to chase a percentage |
| Browser reaction time | Real task response plus screen/input latency; current setup cannot separate human performance from device differences |
| Weekly sauna minutes | Previously retired. Exposure total alone lacks temperature, session pattern and individual context; more is not automatically better |
| Weekly cold-plunge minutes | Previously retired. Temperature, acclimatization and session pattern missing; no universal minutes target |
| Post-thermal HRV rebound | Previously retired. No validated universal rebound target, unstable timing/protocol |
| Systolic blood pressure | Previously retired. Clinically useful, but not an achievement or “as low as possible” target |
| Ankle dorsiflexion | Previously retired. Useful task-specific mobility assessment, but setup and required range depend on the task; excluded from this compact protocol |

## Evidence informing the selection

- [ACSM fitness assessment domains](https://www.acsm.org/wp-content/uploads/2025/01/acsm-ep-crosswalk.pdf): aerobic capacity, muscular fitness and neuromotor assessment. This supports the constructs, not TOP1's exact inventory or game anchors.
- [NICE NG246: waist-to-height assessment](https://www.nice.org.uk/guidance/ng246/chapter/Identifying-and-assessing-overweight-obesity-and-central-adiposity): central adiposity measurement and interpretation.
- [American Heart Association: resting heart rate](https://www.heart.org/en/health-topics/high-blood-pressure/the-facts-about-high-blood-pressure/all-about-heart-rate-pulse): context and normal variation.
- [CDC: adult sleep](https://www.cdc.gov/sleep/data-research/facts-stats/adults-sleep-facts-and-stats.html): adult sleep duration guidance.
- [AASM consumer sleep technology position statement](https://pmc.ncbi.nlm.nih.gov/articles/PMC5940440/): device validation and clinical-use limits. Does not imply all wearable measurements are worthless.
- [American Heart Association: ApoB](https://www.heart.org/en/health-topics/cholesterol/how-to-get-your-cholesterol-tested/apolipoprotein-b) and [Lp(a)](https://www.heart.org/en/health-topics/cholesterol/genetic-conditions/lipoprotein-a): medically useful risk markers, not athletic progress measures.
- Existing test-specific sources and method requirements remain available through each active input's evidence control.

## Compatibility and scoring

Archived values, metadata and observation histories remain stored and exportable. They disappear from entry, search, coverage, current ranking, badges and newly generated scenarios. Saved routines are retained; old scenario versions prompt a new mission. Historical signed summaries remain historical, with their original model version; a new current score can differ because the inventory changed.

Game version: `3-focused-16`. Scientific model version: `6.3-focused16-experimental`. The scientific model still excludes context-only body/recovery readings from its capacity index. Game plateau credit is an illustrative product rule, not medical advice or a published world percentile.
